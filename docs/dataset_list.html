About this list

This is the full, layer-level list of every record in the EcoCommons production catalogue — all 58,424 of them. Use the search box to filter across every column, and click a column header to sort.

Note

Remember that records are not products: one WorldClim variable, for a single model, scenario and month, is its own row, so this list is ~90% WorldClim future-climate layers. For the “what products do we have” view, see the Data Catalogue; for how it was extracted, see the audit.

The table below loads from dataset_list.csv (also available to download). The uuid, data_subcategories and created fields are omitted here for readability — they are in the full extract (prod_dataset_list_full.csv), regenerated on demand by extract_prod_datasets.py.

Code 
data = FileAttachment("data/dataset_list.csv").csv({ typed: true })
Code 
viewof query = Inputs.search(data, {
  placeholder: "Search titles, collections, categories, resolutions…",
  width: "100%"
})
Code 
md`**${query.length.toLocaleString()}** of **${data.length.toLocaleString()}** records shown.`
Code 
Inputs.table(query, {
  rows: 18,
  sort: "Title",
  columns: [
    "Title", "Category", "Time domain", "Year", "Resolution",
    "Spatial domain", "Data type", "Collection", "Downloadable"
  ],
  format: {
    Year: x => (x == null || x === "") ? "" : String(x)
  },
  width: {
    "Title": 320,
    "Category": 85,
    "Time domain": 90,
    "Year": 50,
    "Resolution": 115,
    "Spatial domain": 100,
    "Data type": 90,
    "Collection": 185,
    "Downloadable": 95
  }
})
