Dataset Audit Log

A running record of audit activity, catalogue changes and data-quality findings

A dated, append-only log of changes to the EcoCommons data audit — what was checked or changed, why, and by whom — maintained across each audit pass.
Published

October 13, 2026

Purpose

A living, append-only record of what has changed in the EcoCommons data audit — each catalogue update, rule change and data-quality finding, with the date, the reason and who made it. New entries go at the top.

This is the audit’s memory: the Data Catalogue, Dataset List and Rule Book always show the current state, while this log explains how it got there. For how the underlying data is extracted, see the production catalogue audit.

How to add an entry

Append a new row to the top of the Log table (newest first) with the date (YYYY-MM-DD), the area affected, a one-line description of the change, the reason, and who made it. When a change resolves an item in Open findings, update that item’s status and reference the log entry.
